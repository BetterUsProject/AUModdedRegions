# Contributing

Thanks for your interest in contributing to this project!

## How to Contribute

1. Fork the repository.
2. Create a new branch for your changes.
3. Make your changes.
4. Test your changes.
5. Open a Pull Request.

## Pull Requests

Please make sure that:

- Your code is clean and easy to understand.
- Your changes are relevant to the project.
- You have tested your changes before submitting the Pull Request.
- Your Pull Request clearly explains what was changed.

## Issues

If you find a bug, please open an issue and provide:

- A description of the problem.
- Steps to reproduce it.
- Your environment and version.
- Any relevant logs or screenshots.

For security vulnerabilities, please follow the instructions in `SECURITY.md`.

Thanks for contributing!
