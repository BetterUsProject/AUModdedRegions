# Install Instructions
To install AUModdedRegions, there are multiple methods.

---
**Easy install**

1. Go to the [releases](https://github.com/BetterUsProject/AUModdedRegions/releases) of this project.
2. Download the latest .zip file for your game version (Steam, Epic Games...)
3. Open your Among Us folder and unzip the file you downloaded.
4. Now, launch Among Us to generate the config file.
5. AUModdedRegions is now installed!

**Updating an existing install**

> We're planning on adding a built-in updater to the plugin.

1. Go to the [releases](https://github.com/BetterUsProject/AUModdedRegions/releases) of this project.
2. Download the latest .dll available.
3. Go to your Among Us folder and open BepInEx/plugins.
4. Delete the existing AUModdedRegions.dll file from the folder and replace it with the new one.
5. AUModdedRegions is now updated to the latest version!

**Manual install**

1. Go to the BepInEx [Bleeding Edge builds page](https://builds.bepinex.dev/projects/bepinex_be).
2. Scroll down until you see "Artifacts" and press on the latest artifact available.
3. Download the .zip for your game version:
- Steam/Itch.io: BepInEx-Unity.IL2CPP-win-x86-6.0.0-be.*...*+*...*.zip
- Epic Games/Windows Store: BepInEx-Unity.IL2CPP-win-x64-6.0.0-be.*...*+*...*.zip
4. Unzip the file in your Among Us folder.
5. Go to the [releases](https://github.com/BetterUsProject/AUModdedRegions/releases) of this project.
6. Download the latest .dll file available.
7. In your Among Us folder, put the .dll you downloaded in BepInEx/plugins.
8. AUModdedRegions is now installed!
